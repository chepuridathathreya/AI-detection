# Learning Resources

Ordered by the topics in [yap.txt](yap.txt). Links are from memory and haven't been click-tested, so fix any that have moved.

## 1. Evaluation basics (precision/recall, ROC-AUC, leakage)
- Google ML Crash Course, "Classification" module: https://developers.google.com/machine-learning/crash-course
- scikit-learn docs, "Model evaluation": https://scikit-learn.org/stable/modules/model_evaluation.html
- Stanford CS231n notes (overfitting, splits): https://cs231n.github.io

## 2. PyTorch and transfer learning
- Official PyTorch tutorials, "Transfer Learning for Computer Vision": https://pytorch.org/tutorials
- Andrej Karpathy, "Neural Networks: Zero to Hero" (YouTube)
- fast.ai Practical Deep Learning: https://course.fast.ai

## 3. CLIP, ViT and Hugging Face
- CLIP repo: https://github.com/openai/CLIP
- CLIP paper, "Learning Transferable Visual Models From Natural Language Supervision" (Radford et al., 2021)
- ViT paper, "An Image is Worth 16x16 Words" (Dosovitskiy et al., 2020)
- Hugging Face Course and `transformers` CLIP docs: https://huggingface.co/learn

## 4. The core detection papers (read these first)
- Ojha et al., **"Towards Universal Fake Image Detectors that Generalize Across Generative Models"** (CVPR 2023). CLIP features + linear probe. Best baseline for this project.
- Wang et al., **"CNN-generated images are surprisingly easy to spot... for now"** (CVPR 2020). Shows the generalization problem.
- Rössler et al., **"FaceForensics++"** (ICCV 2019). Deepfake benchmark.
- Corvi et al., "On the detection of synthetic images generated by diffusion models" (ICASSP 2023).

## 5. Calibration
- Guo et al., **"On Calibration of Modern Neural Networks"** (ICML 2017). Temperature scaling and reliability diagrams.
- scikit-learn "Probability calibration" docs.

## 6. Generalization and distribution shift
- Search: "generalization of AI-generated image detectors", "GenImage benchmark".
- Read the evaluation sections of the papers in section 4 closely.

## 7. Image forensics
- Frank et al., "Leveraging Frequency Analysis for Deep Fake Image Recognition" (ICML 2020). GAN/diffusion frequency artifacts.
- Search: "JPEG compression artifacts forensics", "error level analysis".

## 8. Serving
- FastAPI tutorial: https://fastapi.tiangolo.com/tutorial
- ONNX Runtime docs: https://onnxruntime.ai
- PyTorch "Exporting a model to ONNX" tutorial

## 9. C2PA / provenance
- Spec and overview: https://c2pa.org
- Open-source tools (`c2patool`, c2pa-rs): https://github.com/contentauth

## Datasets
- FaceForensics++: https://github.com/ondyari/FaceForensics
- ai-detected/ai-detectors: https://github.com/ai-detected/ai-detectors
- Kaggle: CIFAKE, 140k Real and Fake Faces
- Others to look up: GenImage, DFDC (Deepfake Detection Challenge), Celeb-DF
- Hugging Face Datasets: search "ai generated images detection"

## Suggested reading order
1. Evaluation basics, then PyTorch transfer learning
2. CLIP + Ojha et al. paper (build the baseline while reading)
3. Calibration (Guo et al.)
4. Wang et al. + generalization benchmarks
5. Frequency forensics, then C2PA
6. FastAPI, then ONNX
